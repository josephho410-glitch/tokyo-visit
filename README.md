# 東京參訪隨身助手｜Tokyo Visit PWA V2.9

2026/11/15–11/21 東京參訪個人 iPhone PWA。原生 HTML／CSS／JavaScript，可部署到 GitHub Pages，無帳號與後端服務。

## 功能

- **今天**：最近一筆行程、跨臺灣／日本時間的倒數及下一場正式集合。
- **行程**：七天時間軸、正式集合、交通文字指引、日文地點與導航。正式行程預設須解鎖才可編輯。
- **紀錄**：東京大學 5 題、戶田建設 7 題完整提問與現場回答；其他三場自由筆記。支援 Markdown 匯出及照片索引。
- **購物**：23 間餐廳與 7 處伴手禮購物地點、商品勾選、收藏及個人項目。
- **記帳**：公務／私人實際支出、收據照片、CSV；資金來源另外區分公司預支現金與個人代墊。**交通預算不列入實際支出。**
- **工具**：交通預算、離線文字路線、日文地址、六項真機驗收清單、ICS 行事曆、完整 ZIP 照片備份與還原。

## 使用方式

1. 以 iPhone Safari 開啟 [GitHub Pages 網站](https://josephho410-glitch.github.io/tokyo-visit/)。
2. 分享 → **加入主畫面**。第一次開啟請先連線讓 PWA 完成快取。
3. 使用前先到「工具」進行六項 iPhone 真機測試，尤其確認飛航模式、照片、ZIP 備份與行事曆。
4. 每天匯出「完整 ZIP 備份（含照片）」，儲存至個人受控位置。

## 資料安全

程式碼為公開儲存庫，但個人照片、筆記、費用與預支款數字儲存在使用者裝置，不會自動傳至 GitHub。完整 ZIP 備份**沒有加密**，不要放到公開儲存庫。刪除 Safari 網站資料或移除主畫面 App 可能造成個人資料遺失。

## 技術與限制

本專案採用 localStorage（文字）和 IndexedDB（照片）及 Service Worker（離線快取）。外部 Google／Apple 地圖與即時電車資料需連網，iOS 背景倒數不保證觸發通知。JavaScript／資料遷移測試不代表完成 iPhone 真機測試。
