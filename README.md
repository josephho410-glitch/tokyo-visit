# 東京參訪隨身助手｜Tokyo Visit PWA V2.9（附近探索增量更新）

2026/11/15–11/21 東京參訪 iPhone PWA。靜態 HTML/CSS/JS，GitHub Pages 部署，無後端、無登入、無 API 金鑰。

## 六個主分頁

**今天｜行程｜紀錄｜探索｜記帳｜工具**

「探索」提供「附近餐廳」「伴手禮採買」「我的收藏／購物清單」三個子分頁；原「購物」功能已整合，既有 7 處購物地點、23 間預載餐廳、舊版額外候選、使用者自訂餐廳、購物清單和照片連結均保留。

## 附近探索

1. **依行程推測**：以日本當地日期／時間推測區域，標示非 GPS 定位。也可手動搜尋或選擇區域（手動選取會保存）。
2. **使用目前位置**：只在按鈕按下時請求單次 Geolocation，依附近車站區域中心推估所在區域。精確座標只保留於當次頁面記憶體，**不寫入 localStorage／備份／GitHub**，且不持續追蹤。
3. **餐廳**：來源為現有 `FOOD_SPOTS`、`LEGACY_EXTRA_FOOD`、`db.meals` 與 `db.foodSaved`。以區域、時段、收藏、當日動線及正式集合緩衝計分；先顯示 3 家，可展開全部。缺乏價格、營業、單人用餐或座標者標為待確認，不會編造距離或即時營業狀態。
4. **集合保護**：下一場正式集合及距離時間、可選 20／30／45 分鐘緩衝；不推算缺乏依據的交通和候位時間，**不自動修改正式行程**。
5. **餐廳狀態**：想去、已用餐、不想去、沒營業／找不到；同區替代候選；可加入個人用餐規劃；收藏與自訂餐廳維持原 ID 和照片關聯。

## 東京站伴手禮導覽

**同一閘門區優先**：B1 銀之鈴區／JR 閘門內 AUDREY、富士見堂 → 1F 中央通路／JR 閘門內 Sabrina → 1F 東京ギフトパレット／JR 閘門外 PISTA & TOKYO。

每項商品提供已核對的樓層／區域／閘門狀態、官方店家及樓層圖連結、營業參考、保存方式、照片附件、缺貨／找不到／略過等狀態。尚未核對者以「待確認」顯示。Google、Apple 地圖用於到站，**站內實際櫃位請以官方樓層圖與現場指標為準**。

「開始東京站採買」「準備離開東京站」在 App 開啟時顯示待辦。購買紀錄必須輸入實際盒數和每盒獨立份數，例：3 盒 × 12 份 = 36 份；公司預設 30 份目標可編輯，若超標顯示已達成。可撤銷誤輸入紀錄。舊版商品「已勾選」不代表份數已核對，故**不自動折算份數**。購物金額與原有記帳分開，不會重複入帳。

## 備份、離線與安全

使用 `localStorage` 儲存原有資料及新增 `exploreState`（地區偏好、收藏衍生狀態、購物目標／份數／任務）；照片沿用 `photos.js` 的 IndexedDB 和 `PhotoVault`，不改 schema 或圖片連結。原 JSON／CSV／含照片 ZIP 備份與還原流程保留。備份名稱維持 **V2.9**，備份資料含新增欄位。

`sw.js` 以新的快取鍵納入 `explore.js`。成功完成首次網頁快取後，行程、探索排序、購物任務、照片（已存本機）、記帳可離線。GPS 取決於系統權限，外部導航、官方商品頁、即時列車資訊需網路；無 iPhone 背景持續定位或購物推播保證。

GitHub 儲存庫為公開，**切勿上傳個人備份 ZIP、收據或技術筆記**。ZIP 未加密，請保存在個人受控檔案位置。
